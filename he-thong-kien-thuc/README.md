# Hệ thống kiến thức Mono

Bộ tra cứu chung cho giáo trình Mono (200 buổi, tuổi 4–6), cập nhật 27/11/2026.

- `he-thong-kien-thuc-mono.html`: trang tra cứu 7 tab (sơ đồ tổng, 13 nhóm, 23 chương trình, 368 mục, cách dạy, cơ chế và trò chơi, buổi học và quy tắc).
- `he-thong-kien-thuc-mono.xlsx`: bản Excel 9 trang tính.
- `ht.json`: dữ liệu gốc của cả hai bản.
- `hethong.py`: mã dựng trang từ `ht.json`.

Tầng bậc: 13 nhóm → 23 chương trình → 368 mục (Skill Tree v0.4). Cách dạy: 14 phương pháp → 46 cách học → 26 cơ chế → engine E01–E17.
